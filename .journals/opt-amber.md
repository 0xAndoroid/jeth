## L2 design decisions (sub-word ISA lane)

- **Design A (RamAddress := AlignAddr lookup output, LdAligned/SdAligned) KILLED:** the 19 eq-constraint rows are baked into uni-skip geometry (`SECOND_GROUP_LEN = DOMAIN−1`, 10+9 split, Lagrange base window in jolt-claims/kernels/verifier). Adding a row = protocol-shape change. Guard arithmetic tricks (load+store−add) break ADD rows; no linear escape.
- **Design B (vertex-sum lane tables) CHOSEN:** additive only. k-variants are vertex relabelings — eq(y+k≡v) = eq(y≡v−k) — so one component family serves all 8 k. Uniform bilinear combine with len-gated suffixes:
  `T_k = Σ_w EqLaneP_w·ByteP_{(w+k)&7}·EqLaneS_w + EqLaneP_{(8−k)&7}·Tail_k + Rest_k`
  where Tail_k(bits) = [len≤4]·eqS_{(8−k)&7}·BS_0, Rest_k(bits) = [len≥5]·Σ_w eqS_w·BS_{(w+k)&7}. Index layout (LSB positions): y_i at 2i, x_j at 2j+1; y in suffix ⟺ suffix_len ≥ 5.
- Components: prefixes EqLaneB_w ×8 (default 1, multiplicative eq) + ByteLsb_v ×8 (default 0, additive Σ 2^j x_{8v+j}); suffixes EqLaneBS_w ×8 + Tail_k ×8 + Rest_k ×8. Tables ExtractBu<K> ×8 (IDs appended: 78→86 < 126 ✓). combine may be nonlinear in prefixes, must be LINEAR in suffixes.
- New expansion (LBU only, all imm): align_addr; ld; extract_bu_{imm&7} → 3 rows (−1). LB/LH/LW/SB later phases (B2: clear_lane_b_k + shift_data_b_k → SB 8→6; B3: word variants).
- Kernels consume P/S generically (no per-table kernel work); mirrors needed: jolt-prover-legacy zkvm/*, tracer exec, x86 tracer emit, ABI fixtures, kind.rs.
- Expected B1: −11.67M/781; B1+B2+B3 ≈ −22.5M/781 ≈ −0.52 c/g set-wide.
